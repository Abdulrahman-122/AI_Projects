**Small project: Security Log Data Analyzer**

Project steps:

1. Generate or obtain a CSV containing 10,000 security events.
    
2. Load the data using Pandas.
    
3. Identify missing values and duplicates.
    
4. Extract IP addresses, timestamps and event categories.
    
5. Group events by source IP.
    
6. Calculate failed-login counts per IP.
    
7. Identify IPs with unusual activity.
    
8. Export a cleaned dataset.

    

Deliverable: `security-log-analyzer`.
